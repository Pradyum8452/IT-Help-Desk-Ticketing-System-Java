# IT Help Desk Ticketing and Service Management System Using Java

## 📌 Project Overview

The **IT Help Desk Ticketing and Service Management System** is a Java-based desktop application developed to manage and track technical support requests efficiently.

The system provides a centralized platform where users can raise IT support tickets, administrators can assign tickets to technicians, and technicians can update and resolve assigned issues.

This project was developed as a **Java Programming Micro Project** for the **Department of Electronics and Telecommunication Engineering, Pillai College of Engineering, New Panvel**.

---

## 🎯 Objectives

- Develop a centralized IT support ticket management system.
- Allow users to create and track technical support tickets.
- Allow administrators to manage users and technicians.
- Assign support tickets to appropriate technicians.
- Track ticket status throughout its lifecycle.
- Maintain ticket history and resolution details.
- Demonstrate Java GUI and database connectivity.
- Implement role-based access and secure authentication.

---

## 🚀 Features

### 👤 User

- User login
- Create new support ticket
- Select ticket category
- Set ticket priority
- View personal tickets
- Search tickets using Ticket ID
- Track ticket status
- View resolution details

### 👨‍💼 Administrator

- Admin login
- Dashboard with ticket statistics
- Manage users
- Manage technicians
- View all tickets
- Assign technicians
- Update ticket information
- View ticket history
- Generate ticket reports

### 🧑‍🔧 Technician

- Technician login
- View assigned tickets
- Accept assigned tickets
- Update ticket status
- Add resolution details
- Mark tickets as resolved
